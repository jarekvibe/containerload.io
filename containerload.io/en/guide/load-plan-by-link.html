Pass cargo by link: how one link opens the finished 3D plan

A link of the form containerload.io/app?q=… opens the 3D calculator with the cargo already entered — no account, no key, no API. The cargo sits in the link as text: one position per line, the way you would write it in an enquiry.

The shortest link

https://containerload.io/app?lang=en&q=20 pallets 120x80x110 300kg

Open this link →

That is all it takes. Typed into the address bar, the browser encodes the spaces itself; a program encodes the text like any web address (a space becomes %20). The calculator reads the line, packs the cargo and shows the result in 3D — whoever opens the link can change everything, pass it on or print it as a load proposal.

Several positions

Positions are separated by a semicolon or a line break (%0A). A comma does not separate — in enquiries it too often sits in the middle of a position (“120x80x110, 300 kg”).

https://containerload.io/app?lang=en&q=8 crates 120x80x100 250kg; 12 cartons 60x40x40 12kg not stackable

cont, d and fz only work together with q. The vehicle codes stand for curtainsider semi-trailer, swap body, rigid truck, 7.5-tonner and van. Without cont the calculator starts with a 20ft standard container, adds containers as needed and suggests a better-fitting size.

From Excel: one link per row

With the name (A), quantity (B), length, width, height (C to E) and weight (F) in one row, this formula builds the link:

=HYPERLINK("https://containerload.io/app?lang=en&q=" & ENCODEURL(B2 & " " & A2 & " " & C2 & "x" & D2 & "x" & E2 & " " & F2 & "kg"), "View in 3D")

“Engine block · 4 · 120 · 80 · 95 · 310” becomes the line 4 Engine block 120x80x95 310kg. ENCODEURL is not available in every Excel version; where it is missing, SUBSTITUTE(…," ","%20") replaces the spaces. For the whole list in one link, join the rows with “; ”. If you only want to transfer a list once, you need no formula: select the cells, copy, and paste them in the calculator under “Excel / text”.

From an ERP, TMS or shop

Any system that can put a web address together can produce this link — in the quotation, the order confirmation, the shipping notice. The pattern per position is {quantity} {name} {L}x{W}x{H} {weight}kg, positions joined with “;”, the whole thing encoded as a web address. With one click the recipient sees how their goods sit in the container, and can pass the plan on.

For AI assistants

A language model cannot reliably work out how many packages fit into a container. But it can build this link from a description — and the calculator then gives the answer: a real packing run, visible in 3D and open to checking. The same description in short form for assistants is at /llms.txt.

Limits

  • Length: up to about 2,000 characters a link works everywhere, including mail and chat. Paste longer lists into the calculator and pass on a compact link from “Share”.
  • The link contains the cargo in readable form. Whoever receives it can see it — and like any web address it reaches the server when opened (see Privacy).
  • No return channel: the link opens a page. A program gets no result back; the packing runs in the browser of whoever opens the link.
  • Lines without dimensions are not read — except euro pallets and industrial pallets, whose footprint is fixed.
